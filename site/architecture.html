Architecture

Small core.
Load the rest on demand.

The expensive failure mode is a fat always-on prompt. DevOpt keeps a thin manual, then opens one skill, one pack, and one stack profile.

Tier 0 AGENTS.md · 2,234 token baseline with skill names
Tier 1 One skill body · kickoff, spec, git, release…
Tier 2 One pack One profile One project file

Default stack

Frontend

React + Vite + TypeScript on Netlify. Lives in apps/web. Own git track: dev/frontend → prod/frontend.

Backend

Django 5 + DRF by default. FastAPI or NestJS if you ask. Lives in apps/api. Track: dev/backend → prod/backend.

Git you can actually run

feat/… dev/frontend · dev/backend prod/* only when you say so main = phase archive

Contract between web and API is HTTP, not a shared database. promote.sh dry-runs until a human applies it. Source: ADRs 0001–0003.

Why this saves tokens

Do not load both stacks

A Django session never opens the Nest profile. A web task never opens the API profile. That alone drops thousands of unused tokens.

Do not load every playbook

Fourteen docs in this repo are ~23,600 tokens. The agent opens one. Skills stay as 646 tokens of names until a trigger hits.
