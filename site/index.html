DevOpt v1.1

Install the agent OS. Skip git clone.

One command asks for your project name, backend, and git model, then drops a ready workspace on Linux, macOS, or Windows. Open it in any AI agent and start at phase 0.

macOS / Linux

/bin/bash -c "$(curl -fsSL https://devopt.udithsandaruwan.com/install.sh)"

Needs curl, tar, and bash. Flags: --name my-app --backend django|fastapi|nest --trunk --yes

Windows (PowerShell)

irm https://devopt.udithsandaruwan.com/install.ps1 | iex

Uses Git Bash or WSL to run bootstrap. Git for Windows is enough.

What the installer asks

1. Name and folder

Project name and where to create it. Empty directory only.

2. Backend

Django + DRF (default), FastAPI, or NestJS. Frontend is React + Vite + Netlify.

3. Git model

Promotion tracks (frontend/backend dev + prod, then main) or trunk-based.

Then tell the agent

Read AGENTS.md and project/STATE.md. Run project-kickoff for phase 0.

That is the normal start. For a feature, add the track: frontend or backend. For API work, also: ./scripts/context-pack.sh implement-api.
